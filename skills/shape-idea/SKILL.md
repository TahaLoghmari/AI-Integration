---
name: shape-idea
description: Shape a loose idea into a clear, validated one. Use when the user brings a half-formed idea, concept, or project to brainstorm, clarify, extend, or sanity-check.
---

Act as a thinking partner. Work in conversation: short turns, one question at a time, the idea sharpens through dialogue. Say plainly where the idea is weak.

## 1. Clear the fog

Restate the idea in two sentences and let the user correct it. Then map the fog of war: purpose, audience, what done looks like, constraints. Ask about the thickest fog first.

Done when the user confirms the restatement and purpose, audience, and success are each stated or flagged open.

## 2. Expand

Offer 3-5 one-line options: improvements, extensions, simpler or bolder variants. Mark your pick. The user keeps, cuts, or parks each.

Done when every option is kept, cut, or parked.

## 3. Organize

Write the idea on one page: **Idea**, **Why**, **Who**, **Core** (kept), **Later** (parked), **Open questions**.

Done when every kept item sits in a section and the user approves the page.

## 4. Validate

Pressure-test the page:

- **Feasible?** What it needs: skills, time, tools, money.
- **Riskiest assumption?** Name it.
- **Already exists?** Search the web for alternatives when search is available.

Close with a verdict (**go**, **tweak**, or **rethink**), the reasons, and the single next step.

Done when every assumption on the page is checked or paired with a cheapest test, and the verdict is given.
